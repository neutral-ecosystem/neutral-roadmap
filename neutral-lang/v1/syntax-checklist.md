# Neutral language v1 syntax checklist

Status: intentionally undefined

The current project specifies only Neutral v0. No v1 syntax or feature is
approved, implied, or scheduled.

A v1 checklist may be created only after v0 meets its completion gates and a
concrete, domain-neutral need cannot be satisfied by the v0 core or a data-only
vocabulary. Each proposed feature must define semantics, IR lowering, invalid
states, provenance, resource bounds, compatibility, and conformance evidence.
